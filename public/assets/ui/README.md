# UI Art

Generated pixel-art interface assets used by the title and run scenes.

- `game-cabinet.png`: full 480x800 cabinet backdrop for the game shell
- `instruction-plaque.png`: transparent command plate behind microgame instructions
- `result-badge.png`: transparent feedback badge behind result and game-over text

The generated source images are kept in `public/assets/generated/source`. Text is rendered in Phaser on top of these assets so Japanese and score labels stay crisp and reliable.
